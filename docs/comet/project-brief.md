# 思源 MCP 项目简报

## 一句话描述

为思源笔记开发通用 MCP 服务器和插件，让所有支持 MCP 协议的 AI Agent 都能与思源笔记无缝协作。

## 问题陈述

### 当前痛点
1. **AI 集成分散**: 每个 AI Agent 需要单独适配思源笔记
2. **功能重复开发**: 各个插件重复实现相似的 API 调用逻辑
3. **标准缺失**: 没有统一的协议规范，维护成本高
4. **用户体验割裂**: 不同 AI 工具使用方式不一致

### 目标用户
- 使用 Claude Desktop、Cline、Continue 等 AI 工具的开发者
- 希望在思源笔记中使用 AI 功能的用户
- 需要自动化处理笔记的高级用户

## 解决方案

### 核心价值
1. **标准化接口**: 基于 MCP 协议，一次适配，所有 AI Agent 通用
2. **双重交互**: 既支持 AI Agent 主动调用，也支持插件内手动操作
3. **开箱即用**: 提供完整的配置指南和示例

### 技术方案
- **MCP 服务器**: Node.js + TypeScript，提供标准 MCP 工具
- **思源插件**: Svelte + Vite，提供友好的 UI 界面
- **通信方式**: stdio（Claude Desktop）+ HTTP（插件调用）

## 项目范围

### 第一版本 (v0.1.0) 包含
- ✅ 基础项目结构和配置
- 🔄 MCP 核心工具（搜索、读取、写入）
- ⏳ 思源插件 UI（对话面板、块级操作）
- ⏳ 配置管理和文档

### 第一版本不包含
- ❌ 多用户/多租户支持
- ❌ 云端同步功能
- ❌ 高级 AI 功能（如 RAG、向量检索）
- ❌ 移动端适配
