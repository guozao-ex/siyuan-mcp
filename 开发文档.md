## 项目概述

### 🎯 项目目标

开发一个通用的思源笔记MCP服务器和配套插件，让任何支持MCP协议的AI Agent能够：
- 读取和理解思源笔记内容
- 智能搜索笔记
- 生成内容摘要
- 辅助写作和编辑
- 回答基于笔记的问题

**支持的AI工具**：
- Claude Code CLI
- Cursor IDE
- Windsurf
- Cline (VS Code插件)
- Continue (VS Code/JetBrains插件)
- 任何支持MCP协议的AI工具

## 第一部分：MCP服务器开发

### 📦 什么是MCP？

**MCP (Model Context Protocol)** 是由Anthropic推出的开放标准协议，让AI Agent能够安全、标准化地访问外部数据源。

**通俗理解**：就像USB接口标准让不同设备能通用一样，MCP让不同的AI工具（Claude、Cursor、Windsurf等）都能用统一的方式访问思源笔记，无需为每个工具单独开发适配器。

**MCP的优势**：
- ✅ **标准化** - 一次开发，所有支持MCP的AI工具都能使用
- ✅ **安全性** - 明确的权限控制和数据访问边界
- ✅ **可扩展** - 易于添加新功能和工具
- ✅ **互操作性** - 不同AI工具之间能共享数据访问能力

```typescript
export interface SiyuanResponse<T = any> {
  code: number;      // 0表示成功
  msg: string;       // 错误消息
  data: T;           // 返回数据
}

/** 笔记本信息 */
export interface Notebook {
  id: string;        // 笔记本ID
  name: string;      // 笔记本名称
  icon: string;      // 图标
  closed: boolean;   // 是否关闭
}

/** 块信息 */
export interface Block {
  id: string;        // 块ID
  type: string;      // 块类型：d=文档, p=段落, h=标题等
  content: string;   // 块内容
  parent_id?: string;
  root_id: string;   // 所属文档ID
}

/** 搜索结果 */
export interface SearchResult {
  blocks: Block[];
  matchedBlockCount: number;
  matchedRootCount: number;
}

/** 文档树 */
export interface DocTree {

  name: string;
  path: string;
  type: string;
```

创建 `mcp-server/src/siyuan/api.ts`：

```typescript
import { SiyuanResponse, Notebook, Block, SearchResult } from './types.js';

/** 思源笔记API客户端 */
export class SiyuanAPI {
  private baseUrl: string;
  private token: string;

  constructor(baseUrl = 'http://127.0.0.1:6806', token: string) {
    this.baseUrl = baseUrl;
    this.token = token;
  }

  /** 通用请求方法 */
  private async request<T>(endpoint: string, data: any = {}): Promise<T> {
    const response = await fetch(`${this.baseUrl}${endpoint}`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Token ${this.token}`
      },
      body: JSON.stringify(data)
    });

    if (!response.ok) {
      throw new Error(`HTTP Error: ${response.status}`);
    }

    const result: SiyuanResponse<T> = await response.json();
    
    if (result.code !== 0) {
      throw new Error(`SiYuan API Error: ${result.msg}`);
    }

    return result.data;
  }

  /** 获取所有笔记本 */
  async listNotebooks(): Promise<Notebook[]> {
    const data = await this.request<{ notebooks: Notebook[] }>('/api/notebook/lsNotebooks');
    return data.notebooks;
  }

  /** 全文搜索 */
  async searchBlocks(query: string): Promise<SearchResult> {
    return this.request<SearchResult>('/api/search/fullTextSearchBlock', {
      query
    });
  }

  /** 获取块内容（Kramdown格式） */
  async getBlockKramdown(blockId: string): Promise<string> {
    const data = await this.request<{ kramdown: string }>('/api/block/getBlockKramdown', {
      id: blockId
    });
    return data.kramdown;
  }

  /** 创建文档 */
  async createDocument(notebook: string, path: string, markdown: string): Promise<string> {
    const data = await this.request<{ id: string }>('/api/filetree/createDocWithMd', {
      notebook,
      path,
      markdown
    });
    return data.id;
  }

  /** 更新块内容 */
  async updateBlock(blockId: string, markdown: string): Promise<void> {
    await this.request('/api/block/updateBlock', {
      id: blockId,
      dataType: 'markdown',
      data: markdown
    });
  }

  /** 追加块 */
  async appendBlock(parentId: string, markdown: string): Promise<string> {
    const data = await this.request<{ id: string }>('/api/block/appendBlock', {
      parentID: parentId,
      dataType: 'markdown',
      data: markdown
    });
    return data.id;
  }

  /** SQL查询 */
  async querySQL(sql: string): Promise<any[]> {
    const data = await this.request<any[]>('/api/query/sql', {
      stmt: sql
    });
    return data;
  }

  /** 获取系统版本 */
  async getVersion(): Promise<string> {
    const data = await this.request<string>('/api/system/version');
    return data;
  }
}
```

```typescript
import { SiyuanAPI } from '../siyuan/api.js';

/** 搜索笔记工具 */
export async function searchNotesTool(api: SiyuanAPI, query: string) {
  // 调用思源API搜索
  const result = await api.searchBlocks(query);
  
  // 格式化结果，转换为AI友好的格式
  const formattedResults = result.blocks.map(block => ({
    id: block.id,
    content: block.content,
    type: block.type,
    documentId: block.root_id
  }));

  return {
    success: true,
    totalCount: result.matchedBlockCount,
    results: formattedResults
  };
}
```

### 🎯 第四步：创建MCP服务器主程序

创建 `mcp-server/src/index.ts`：

```typescript
#!/usr/bin/env node
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import {
  CallToolRequestSchema,
  ListToolsRequestSchema,
} from '@modelcontextprotocol/sdk/types.js';
import { SiyuanAPI } from './siyuan/api.js';
import { searchNotesTool } from './tools/search.js';
import { readBlockTool } from './tools/read.js';
import { createDocumentTool, updateBlockTool } from './tools/write.js';

// 从环境变量获取配置
const SIYUAN_TOKEN = process.env.SIYUAN_TOKEN || '';
const SIYUAN_URL = process.env.SIYUAN_URL || 'http://127.0.0.1:6806';

if (!SIYUAN_TOKEN) {
  console.error('Error: SIYUAN_TOKEN environment variable is required');
  process.exit(1);
}

// 创建思源API客户端
const siyuanAPI = new SiyuanAPI(SIYUAN_URL, SIYUAN_TOKEN);

// 创建MCP服务器
const server = new Server(
  {
    name: 'siyuan-mcp-server',
    version: '0.1.0',
  },
  {
    capabilities: {
      tools: {},
    },
  }
);

// 注册工具列表
server.setRequestHandler(ListToolsRequestSchema, async () => {
  return {
    tools: [
      {
        name: 'search_notes',
        description: '在思源笔记中搜索内容。支持全文搜索，返回匹配的块列表。',
        inputSchema: {
          type: 'object',
          properties: {
            query: {
              type: 'string',
              description: '搜索关键词或短语'
            }
          },
          required: ['query']
        }
      },
      {
        name: 'read_block',
        description: '读取指定块的内容。返回Markdown格式的文本。',
        inputSchema: {
          type: 'object',
          properties: {
            blockId: {
              type: 'string',
              description: '块ID（14位时间戳+7位字符）'
            }
          },
          required: ['blockId']
        }
      },
      {
        name: 'create_document',
        description: '创建新文档。可以用Markdown格式编写内容。',
        inputSchema: {
          type: 'object',
          properties: {
            notebook: {
              type: 'string',
              description: '笔记本ID'
            },
            path: {
              type: 'string',
              description: '文档路径，如 /文件夹/文档名'
            },
            content: {
              type: 'string',
              description: 'Markdown格式的文档内容'
            }
          },
          required: ['notebook', 'path', 'content']
        }
      },
      {
        name: 'update_block',
        description: '更新现有块的内容。',
        inputSchema: {
          type: 'object',
          properties: {
            blockId: {
              type: 'string',
              description: '要更新的块ID'
            },
            content: {
              type: 'string',
              description: '新的Markdown内容'
            }
          },
          required: ['blockId', 'content']
        }
      },
      {
        name: 'list_notebooks',
        description: '列出所有笔记本。',
        inputSchema: {
          type: 'object',
          properties: {}
        }
      }
    ]
  };
});

// 处理工具调用
server.setRequestHandler(CallToolRequestSchema, async (request) => {
  try {
    const { name, arguments: args } = request.params;

    switch (name) {
      case 'search_notes': {
        const result = await searchNotesTool(siyuanAPI, args.query as string);
        return {
          content: [
            {
              type: 'text',
              text: JSON.stringify(result, null, 2)
            }
          ]
        };
      }

      case 'read_block': {
        const result = await readBlockTool(siyuanAPI, args.blockId as string);
        return {
          content: [
            {
              type: 'text',
              text: result.content
            }
          ]
        };
      }

      case 'create_document': {
        const result = await createDocumentTool(
          siyuanAPI,
          args.notebook as string,
          args.path as string,
          args.content as string
        );
        return {
          content: [
            {
              type: 'text',
              text: JSON.stringify(result, null, 2)
            }
          ]
        };
      }

      case 'update_block': {
        const result = await updateBlockTool(
          siyuanAPI,
          args.blockId as string,
          args.content as string
        );
        return {
          content: [
            {
              type: 'text',
              text: JSON.stringify(result, null, 2)
            }
          ]
        };
      }

      case 'list_notebooks': {
        const notebooks = await siyuanAPI.listNotebooks();
        return {
          content: [
            {
              type: 'text',
              text: JSON.stringify(notebooks, null, 2)
            }
          ]
        };
      }

      default:
        throw new Error(`Unknown tool: ${name}`);
    }
  } catch (error) {
    return {
      content: [
        {
          type: 'text',
          text: `Error: ${error.message}`
        }
      ],
      isError: true
    };
  }
});

// 启动服务器
async function main() {
  const transport = new StdioServerTransport();
  await server.connect(transport);
  console.error('SiYuan MCP Server running on stdio');
}

main().catch((error) => {
  console.error('Server error:', error);
  process.exit(1);
});
```

修改 `mcp-server/src/index.ts`，添加HTTP服务器：

```typescript
import { createServer } from 'http';

// ... 现有代码 ...

// 添加HTTP服务器（用于插件直接调用）
const httpServer = createServer(async (req, res) => {
  // 设置CORS
  res.setHeader('Access-Control-Allow-Origin', '*');
  res.setHeader('Access-Control-Allow-Methods', 'POST, OPTIONS');
  res.setHeader('Access-Control-Allow-Headers', 'Content-Type');
  
  if (req.method === 'OPTIONS') {
    res.writeHead(200);
    res.end();
    return;
  }
  
  if (req.method !== 'POST') {
    res.writeHead(405);
    res.end('Method Not Allowed');
    return;
  }
  
  let body = '';
  req.on('data', chunk => body += chunk);
  req.on('end', async () => {
    try {
      const { tool, arguments: args } = JSON.parse(body);
      
      // 调用对应的工具
      let result;
      switch (tool) {
        case 'search_notes':
          result = await searchNotesTool(siyuanAPI, args.query);
          break;
        case 'read_block':
          result = await readBlockTool(siyuanAPI, args.blockId);
          break;
        // ... 其他工具
        default:
          throw new Error(`Unknown tool: ${tool}`);
      }
      
      res.writeHead(200, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify(result));
    } catch (error) {
      res.writeHead(500, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ error: error.message }));
    }
  });
});

const HTTP_PORT = process.env.HTTP_PORT || 3000;
httpServer.listen(HTTP_PORT, () => {
  console.error(`HTTP server listening on port ${HTTP_PORT}`);
});
```

然后在插件中调用：

```typescript
// siyuan-plugin/src/api/mcp.ts
export class MCPClient {
  private baseUrl: string;
  
  constructor(baseUrl = 'http://127.0.0.1:3000') {
    this.baseUrl = baseUrl;
  }
  
  async callTool(tool: string, args: any) {
    const response = await fetch(this.baseUrl, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ tool, arguments: args })
    });
    
    if (!response.ok) {
      throw new Error(`HTTP Error: ${response.status}`);
    }
    
    return response.json();
  }
  
  async searchNotes(query: string) {
    return this.callTool('search_notes', { query });
  }
  
  async readBlock(blockId: string) {
    return this.callTool('read_block', { blockId });
  }
}
```

```markdown
      "env": {
        "SIYUAN_TOKEN": "你的API-Token"

  }
}
```

## 常见问题

### ❓ MCP服务器无法连接思源笔记

**解决方法**：
1. 确认思源笔记正在运行
2. 检查API Token是否正确
3. 确认端口6806没有被占用
4. 查看思源日志：`工作空间/temp/siyuan.log`

### ❓ AI客户端找不到MCP工具

**解决方法**：
1. 检查配置文件路径是否正确
2. 确认Node.js路径正确
3. 查看AI客户端的日志输出
4. 重启AI客户端或终端

### ❓ 插件加载失败

**解决方法**：
1. 检查 `plugin.json` 格式是否正确
2. 确认 `minAppVersion` 与思源版本兼容
3. 查看浏览器控制台错误信息
4. 重新构建插件

### ❓ CORS跨域错误

**解决方法**：
在MCP HTTP服务器中添加CORS头（已包含在示例代码中）

### ❓ TypeScript编译错误

**解决方法**：
```bash
# 删除node_modules和lock文件
rm -rf node_modules pnpm-lock.yaml

# 重新安装
pnpm install
```
